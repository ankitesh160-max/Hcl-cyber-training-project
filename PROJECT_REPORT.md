# SecureStep – Two-Factor Authentication System

## Abstract

SecureStep is a web-based two-factor authentication demonstration built with HTML, CSS, JavaScript, Node.js, Express.js, bcryptjs, Speakeasy, QRCode, and Express Session. The system first verifies an email and password and then requires a six-digit TOTP code generated by an authenticator application.

## Problem Statement

Password-only authentication has weaknesses because users may reuse passwords, choose weak passwords, or have credentials exposed in breaches. Two-factor authentication adds a second verification step, reducing the usefulness of a stolen password by itself.

## Objectives

1. Build a working local authentication system.
2. Hash passwords before storage.
3. Generate unique TOTP secrets.
4. Provide QR-code authenticator setup.
5. Verify an initial OTP before enabling 2FA.
6. Require password and OTP during login.
7. Protect the dashboard using sessions.
8. Add rate limiting and input validation.
9. Keep the implementation simple enough for student learning.

## System Architecture

The browser communicates with an Express server using JSON API requests. The server validates data, checks password hashes, handles TOTP operations, manages sessions, and reads/writes user records.

## Security Flow

Registration:
Name + Email + Password
-> validate
-> bcrypt hash password
-> generate TOTP secret
-> store user
-> generate QR
-> verify first TOTP
-> enable 2FA

Login:
Email + Password
-> bcrypt comparison
-> pending session
-> TOTP verification
-> session regeneration
-> authenticated session
-> dashboard

## Expected Results

A correctly registered user can configure an authenticator application, verify the initial TOTP, log in using password + TOTP, access the protected dashboard, and log out. Incorrect credentials or OTPs are rejected.

## Conclusion

SecureStep demonstrates the core idea behind multi-factor authentication in a small, understandable web application. It is appropriate as a college learning project and a base for studying authentication, password hashing, sessions, TOTP, QR codes, and rate limiting.
